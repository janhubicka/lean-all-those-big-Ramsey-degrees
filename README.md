# All those big Ramsey degrees — Lean

Companion formalization of `janhubicka/All-those-big-Ramsey-degrees`.

The project uses full quantifier-free types. Type-respecting means n-type-respecting for n equal to the maximum relation arity minus one. Ordinary big Ramsey degrees are defined using all embeddings.

Foundational definitions, source correspondence, and validation status are maintained in this repository. No general upper-bound theorem or unrestricted weak-to-full amalgamation implication is assumed.
